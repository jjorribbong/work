> 새 세션에서는 이 파일들이 없으므로 작업 시작 시 양식을 다시 업로드받아 같은 파일명으로 이 폴더에 저장합니다.

## 폴더 구조
```
regulation/
├── templates/                     # 공식 양식 (요청서+신구대비표)
├── reference/                     # 내부 작성 기준 원본
├── input/{YYYYMMDD}_{규정명}/      # 원본 규정 파일 (수정 금지)
├── input/검토의견/                 # 검토의견 엑셀 (수정 금지)
└── output/{YYYYMMDD}_{규정명}/     # 개정요청서및신구대비표.hwpx, 개정안 규정파일, 검증보고.md
```
