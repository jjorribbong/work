# 규정 개정 양식 보관함

규정 개정 시 사용하는 공식 양식을 이 폴더에 보관합니다. (지침: `.claude/skills/regulation-revision/SKILL.md`)

| 양식 | 파일명 | 등록 상태 |
|------|--------|-----------|
| 규정 개정 요청서 | (업로드 대기) | ⬜ 미등록 |
| 신구대비표 | (업로드 대기) | ⬜ 미등록 |

양식 파일을 업로드하면 이 표를 갱신하고, 이후 모든 규정 개정에 동일하게 사용합니다.

## 폴더 구조
```
regulation/
├── templates/                     # 공식 양식 (요청서, 신구대비표)
├── input/{YYYYMMDD}_{규정명}/      # 원본 규정 파일, 검토의견 엑셀 (수정 금지)
└── output/{YYYYMMDD}_{규정명}/     # 개정요청서, 신구대비표, 개정안 규정파일, 검증보고.md
```
