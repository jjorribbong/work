# AI기기 인스펙터 (Android)

시험 감독관의 Android 휴대폰에서, 고사장 안에 **켜져 있고 무선 신호를 내보내는 전자기기**를 찾아 주는 앱입니다.
신호를 듣기만 하고 내보내지 않으며(전파 차단 없음), 서버 없이 휴대폰 안에서만 동작합니다.

## 기능

| 기능 | 설명 |
|---|---|
| 블루투스(BLE) 스캔 | 스마트워치, 무선이어폰, 스마트안경, 블루투스가 켜진 휴대폰·태블릿·노트북 |
| Wi-Fi 스캔 | 핫스팟을 켠 휴대폰 (Wi-Fi 이름, 무작위 주소로 추정) |
| 기기 종류 판별 | 기기 이름, 제조사 ID(Apple·Samsung·Meta·Google 등), Apple 신호 종류, 서비스 UUID로 추정 |
| 기준 등록 | 시험 전에 누르면 이미 있던 기기(감독관 폰, 교실 공유기)는 경고에서 빠지고, 이후 새로 나타난 의심 기기만 진동으로 알림 |
| 추적 모드 | 기기를 누르면 신호 세기에 따라 "멀리 있음 → 바로 근처"로 표시되고, 가까울수록 삐 소리가 빨라짐 |
| 기록 내보내기 | 경고 기록과 탐지 목록을 CSV 텍스트로 공유 (주소는 뒤 두 자리만 남김) |

## 사용 순서

1. 앱을 열고 권한(근처 기기, 위치)을 허용합니다. 휴대폰의 **블루투스, Wi-Fi, 위치(GPS)를 모두 켭니다.**
2. 학생 입실 전, 교실 가운데에서 1분쯤 스캔한 뒤 **기준 등록**을 누릅니다.
3. 시험 중에는 화면에 **의심 기기**와 **새로 나타난 기기**가 표시되고, 휴대폰이 진동합니다.
4. 의심 기기를 누르면 추적 모드로 바뀝니다. 휴대폰을 들고 천천히 걸으며 "바로 근처"가 뜨는 자리를 찾습니다.
5. 시험이 끝나면 **기록 내보내기**로 증빙을 남기고 **모든 기록 지우기**를 누릅니다.

## 한계 (꼭 알아 두세요)

- **탐지할 수 없음**: 비행기 모드인 기기, 블루투스와 Wi-Fi가 모두 꺼진 기기, LTE/5G 통신만 하는 휴대폰. 이런 기기는 전용 전파탐지기나 금속탐지기로 찾아야 합니다.
- **거리는 대략적**: 신호 세기는 몸, 가방, 벽 때문에 크게 흔들립니다. "약 2m"는 참고용입니다.
- **주소가 바뀌는 기기**: iPhone, 최신 Galaxy 등은 개인정보 보호를 위해 블루투스 주소를 약 15분마다 바꿉니다. 그래서 기준 등록 후에도 감독관 본인의 기기가 "신규"로 다시 뜰 수 있습니다. 감독관 기기는 블루투스를 끄거나, 경고가 뜨면 추적 모드로 위치를 확인하세요.
- **종류 판별은 추정**: 이름을 숨긴 기기는 "기타 블루투스"나 "미확인"으로 나옵니다. 분류 규칙은 `app/src/main/java/kr/examguard/inspector/model/DeviceClassifier.kt` 에서 추가할 수 있습니다.
- **앱이 화면에 떠 있을 때만 스캔합니다** (화면은 자동으로 꺼지지 않게 해 두었습니다).

## 빌드

- **GitHub Actions**: 이 폴더를 수정해 푸시하면 `.github/workflows/ai-device-inspector.yml` 이 테스트하고 APK를 만듭니다. Actions 실행 화면의 Artifacts에서 `ai-device-inspector-apk` 를 내려받아 휴대폰에 설치하세요 (설치 시 "출처를 알 수 없는 앱" 허용 필요).
- **Android Studio**: 이 `ai-device-inspector` 폴더를 열고 실행 버튼을 누르면 됩니다.
- **명령줄**: Android SDK가 설치된 PC에서 `./gradlew assembleDebug`

요구 사양: Android 8.0(API 26) 이상, 블루투스 저전력(BLE) 지원 기기.

## 구조

```
app/src/main/java/kr/examguard/inspector/
├── MainActivity.kt          권한 요청, 화면 켜짐 유지, 기록 공유
├── ScanViewModel.kt         탐지 목록, 기준 등록, 경고, CSV 내보내기
├── scan/Scanners.kt         BLE 스캐너, Wi-Fi 스캐너
├── model/DetectedDevice.kt  기기 데이터, 신호 평활화, 거리 추정
├── model/DeviceClassifier.kt 기기 종류 판별 규칙
└── ui/InspectorApp.kt       메인 화면, 추적 화면 (Jetpack Compose)
```
