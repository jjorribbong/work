# 서원대학교 규정집 앱 — 담당자용 안내

서원대학교 홈페이지 규정집의 규정을 휴대폰에서 검색하고, 규정 간 위임·인용 관계와 상위 법령(국가법령정보센터)과의
차이를 점검하는 웹앱입니다. 이 폴더에는 앱 코드와 데이터 수집 프로그램, 그리고 **Claude가 앱을 만드는 순서(CLAUDE.md)**가
들어 있습니다. 코딩을 몰라도 Claude에게 맡겨 만들 수 있습니다.

## 앱으로 할 수 있는 것

- **검색**: 규정명·본문 낱말 검색, 개정 기간으로 바뀐 조문 찾기
- **규정목록**: 편별 목록, 즐겨찾기, 최근 개정 규정과 조문별 신구 대비
- **위임관계**: 규정별 상위(근거)·하위(위임) 규정, 준용·참조
- **검증**: 없는 규정·조 인용, 폐지 법령 인용, 상위법과 숫자·문장 비교, 규정 간 중복 조항
- 규정 보기에서 현행 규정 HWP·신구조문대비표 바로 받기, 휴대폰 홈 화면에 앱처럼 설치

## 준비물

| 준비물 | 용도 | 비고 |
| --- | --- | --- |
| Windows PC (학교 PC 권장) | 규정 수집·법령 확인 실행 | 인터넷 연결 필요 |
| Claude Code (Claude 데스크톱 앱의 Code 탭 또는 터미널) | 이 폴더를 열고 작업 실행 | Claude 유료 요금제 |
| Python 3.9 이상, Node.js 18 이상 | 수집·점검 프로그램 | 없으면 Claude가 설치를 안내 |
| GitHub 계정 | 앱 공개(GitHub Pages, 무료) | 공개 저장소 |
| 국가법령정보센터 OPEN API 인증키(OC) | 상위법 비교용 법령 받기 | open.law.go.kr에서 신청, **실행할 PC의 공인 IP 등록** (승인에 시간이 걸릴 수 있으니 먼저 신청) |

> 인터넷 브라우저의 claude.ai 채팅만으로는 학교 사이트·법령 API에 접속할 수 없어 만들 수 없습니다.
> **PC에서 실행되는 Claude Code**를 쓰세요. 법령 API는 등록한 IP에서만 되므로 그 PC에서 실행해야 합니다.

## 만드는 방법 (Claude Code)

1. 이 폴더(압축을 푼 `seowon-kit`)를 원하는 위치에 둡니다. 예: `C:\seowon-rules`
2. Claude Code에서 이 폴더를 엽니다.
   - 데스크톱 앱: Code 탭 → 폴더 선택
   - 터미널: `cd C:\seowon-rules` 후 `claude`
3. 아래 문장을 입력합니다.

   ```
   CLAUDE.md를 읽고 그 순서대로 서원대학교 규정집 앱을 만들어줘. 국가법령정보센터 인증키는 나중에 물어봐줘.
   ```

4. Claude가 진행하면서 묻는 것에 답합니다.
   - 프로그램 실행 허락(설치·실행 명령) → 내용을 보고 허용
   - 법령 API 인증키(OC) → 신청한 값 입력(아직 없으면 "나중에"라고 답하면 법령 비교 없이 먼저 만듭니다)
   - GitHub 저장소 만들기·올리기 → 안내대로 로그인·클릭
5. 끝나면 `https://GitHub아이디.github.io/저장소이름/` 주소가 생깁니다. 휴대폰에서 열고 **홈 화면에 추가**를 누르세요.

전체 과정은 처음 한 번 30분~1시간 정도 걸립니다(규정 수집 5~10분, 법령 확인 3~5분 포함).

## 규정이 개정되면

- **방법 1 (버튼 한 번)**: `tools\규정업데이트.bat` 더블클릭 → 처음 한 번 인증키·GitHub 토큰·저장소 입력 → **업데이트 시작**
- **방법 2 (Claude)**: Claude Code에서 "규정 데이터 업데이트해서 올려줘"

앱은 다음에 열 때 자동으로 새 데이터로 바뀝니다.

## 알아둘 점

- 자동 점검 결과는 문언 패턴으로 찾은 **검토 후보**입니다. 법률 자문이 아니며 최종 판단은 원문과 담당 부서가 합니다.
- 인증키·GitHub 토큰은 다른 사람과 공유하거나 저장소에 올리지 마세요(업데이트 프로그램은 이 PC에만 저장합니다).
- 학교 규정집 사이트 구조가 바뀌면 수집이 실패할 수 있습니다. 그때는 Claude에게 "수집이 실패해. docs/site-structure.md 보고 고쳐줘"라고 하세요.
- 이 앱은 청주대학교 규정집 앱과 같은 화면·분석 엔진을 쓰고, 서원대 규정집(HWP 파일)에 맞게 수집 부분을 새로 만든 것입니다.
