# 청주대학교 규정집 (모바일 웹앱)

청주대학교 규정관리시스템(https://rule.cju.ac.kr/lmxsrv/main/main.srv)의 규정을 휴대폰에서 검색하고,
규정 간 위임조항과 동일·유사 내용을 검증하는 웹앱입니다. GitHub Pages 주소의 `/rules/`에서 열고,
브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 설치됩니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| 검색 | 규정명·본문 검색(전체/규정명/본문), 띄어쓰기 무시, 여러 낱말 AND, `"구절"` 검색, 분류 필터, 최근 검색어 |
| 규정목록 | 분류별 목록, 즐겨찾기 |
| 위임관계 | 규정별 상위(근거)·하위(위임) 규정, 위임 체계도, 준용·참조, 대상 미지정 위임("별도로 정한다"), 외부 법령 인용 |
| 검증 | **정합성 점검**: 없는 규정·조항 인용, 근거 조항에 위임 문언 없음, 하위 규정 미확인 등<br>**동일·유사 조항**: 조·항 단위 중복 검출, 차이 부분 표시, 기간·학점·인원 등 숫자 불일치 표시<br>**두 규정 비교** |
| 데이터 | 최신 데이터 받기, JSON·HWPX·DOCX·TXT 가져오기, 본문 붙여넣기, 내보내기 |

규정 보기 화면에서는 「규정명」·제N조 인용이 링크로 바뀌고(없는 대상은 빨간 물결선), 조마다 위임·근거 배지와
**유사 조항 찾기**가 있습니다.

## 규정 데이터 수집

규정관리시스템은 보안 정책(CORS) 때문에 다른 주소의 웹앱이 직접 읽을 수 없습니다. 그래서 수집기로
전문을 모아 `rules/data/rules.json`으로 올려 두면 앱이 그 파일을 읽습니다.

```bash
pip install -r rules/tools/requirements.txt
python rules/tools/cju_rules_crawler.py            # 목록 자동 탐색 → rules/data/rules.json
git add rules/data/rules.json && git commit -m "규정 데이터 갱신" && git push
```

자동 탐색이 안 되면:

- `--viewer "/lmxsrv/law/....srv?SEQ={seq}"`: 브라우저로 규정 하나를 열었을 때 주소 형식을 지정
- `--scan 1-3000`: 규정 번호(SEQ) 범위를 직접 지정
- `--from-dir 폴더`: 브라우저에서 "다른 이름으로 저장"한 규정 HTML/TXT 파일에서 추출
- `--insecure`: 인증서 오류가 날 때만 사용

학교 서버에 부담을 주지 않도록 요청 사이에 0.5초(`--delay`) 쉽니다. 학교 밖·해외 IP는 막혀 있을 수 있으니
교내망 PC에서 실행하는 것을 권장합니다.

## 분석 기준

- **위임**: 「규정명」 뒤에 "으로/에서 정한다" → 이 조항이 대상 규정에 위임
- **근거**: 「규정명」 제N조 뒤에 "에 따라/에 의하여/의 위임" → 이 규정이 그 조항에 근거
- **준용**: "~을 준용한다"
- 괄호 없이 쓴 규정명도 등록된 규정명과 일치하면 인식합니다. 「고등교육법」 같은 외부 법령은 검증 대상에서 뺍니다.
- 동일·유사 조항: 공백·문장부호·항 번호를 없앤 뒤 4글자 조각의 겹침(자카드 유사도) 또는 한쪽이 다른 쪽에
  포함된 비율로 판정합니다.

자동 분석은 문언 패턴에 기반하므로, 결과는 검토 대상 목록으로 활용하고 최종 판단은 원문으로 확인해 주세요.

## 파일

- `index.html`: 앱 화면
- `engine.js`: 파싱·검색·위임 분석·유사도 엔진 (Node에서도 `require` 가능)
- `data/sample.json`: 체험용 예시 데이터 (실제 규정 아님)
- `data/rules.json`: 수집기 출력 (수집 후 추가)
- `tools/cju_rules_crawler.py`: 규정 수집기
