👂 마주톡

휴대폰을 가로로 놓으면 글자가 화면 가득 두 줄로 나와요.
마주 앉을 때는 ⇅ 마주보기를 누르고 휴대폰을 세로로 두세요.

설정

글자 크기
마주보기 (세로 화면, 위쪽은 뒤집어 맞은편에서 읽기)
└ 엄마 쪽 화면 비율
└ 엄마 쪽 글자 크기 (왼쪽일수록 큼)
└ 내 쪽 글자 크기 (왼쪽일수록 큼)
흰 바탕 화면
새 글자가 나오면 진동
자주 틀리는 말 고치기

한 줄에 하나씩 틀린말 = 바른말. 가족 이름·약 이름처럼 자주 틀리는 말을 자동으로 고쳐 줘요.

🎤 더 잘 알아듣게 하려면

· 휴대폰 마이크에 30cm 안쪽에서, 문장마다 끝에서 잠깐 쉬며 말해 주세요.
· TV·음악 소리를 줄여 주세요.
· 크롬(Chrome) 앱에서 여는 것이 가장 정확해요. 삼성 인터넷·카카오톡 안에서는 잘 안 돼요.
· 휴대폰 설정 → 일반 → 키보드 → Google 음성 입력 → 언어에 한국어가 있는지 확인하세요.
