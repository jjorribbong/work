적용 순서: **① 청주대학교 내부 기준 → ② 법제처 「법령 입안·심사 기준」**
(충돌 시 내부 기준 우선. 기준이 불분명하면 현행 규정의 기존 표기 방식을 따르고, 그래도 불분명하면 사용자에게 확인)

---

## Ⅰ. 청주대학교 내부 기준

> 사용자가 알려주는 내부 기준을 여기에 계속 추가한다. (미등록 항목은 Ⅱ 법령입안심사기준 적용)

1. (등록 대기) 
2. 규정집에 실린 현행 규정의 표기 관행(조문 제목 괄호, 항 번호 원문자, 개정 이력 표기 등)을 유지한다.

---

## Ⅱ. 법령입안심사기준 주요 사항

### 1. 조문 체계
- 편·장·절·관 → 조 → 항 → 호 → 목 순서.
  - 조: `제1조(목적)` — 조 번호 뒤 괄호 안에 조문 제목
  - 항: `①, ②, ③ …`
  - 호: `1., 2., 3. …`
  - 목: `가., 나., 다. …`
  - 목 아래 세분: `1), 2) …` → `가), 나) …` 
- 항이 하나뿐인 조에는 ①을 붙이지 않는다.
- 첫 조는 `제1조(목적)`, 용어 정의가 필요하면 `제2조(정의)`. 
- 조문 중간 신설은 가지번호 사용: `제5조의2`, 항은 `②의2` 대신 원칙적으로 항 번호를 새로 매기되, 전체 번호를 밀면 인용 조문이 많이 바뀔 경우 가지번호/조 신설로 처리. 
- 조·항·호를 삭제할 때 번호를 당기지 않고 `제7조 삭제 <2026. 11. 13.>` 처럼 남겨 둔다(일부개정 시). 전부개정이면 번호를 새로 정리.

### 2. 인용 표기
- 붙여 쓴다: `제3조제1항제2호가목`
- 같은 조 안의 인용: `제1항에 따라`, `이 조 제2항`
- 다른 규정 인용: 「〇〇규정」 제5조 — 홑낫표 「 」 사용, 법령은 「고등교육법」 제2조
- 앞 조문 인용 시 "전조", "전항" 쓰지 않고 정확한 번호로 쓴다.
- 조문 신설·삭제·이동 시 규정 전체의 인용 조문을 검색하여 함께 정비한다.

### 3. 개정 이력 표기
- 개정된 조·항·호 끝: `<개정 2026. 11. 13.>`
- 신설: `<신설 2026. 11. 13.>`
- 삭제: `삭제 <2026. 11. 13.>`
- 여러 차례 개정: `<개정 2020. 3. 1., 2026. 11. 13.>`
- 날짜는 공포(공고)일 또는 개정일 기준 — 학교 관행 확인.

### 4. 부칙
- 개정 시 반드시 부칙을 둔다: 
  ```
  부    칙
  이 규정은 2026년 12월 1일부터 시행한다.
  ```
  - 여러 조이면 `제1조(시행일)`, `제2조(경과조치)`, `제3조(다른 규정의 개정)` 형식.
  - 공포 즉시 시행: `이 규정은 공포한 날부터 시행한다.`
  - 기존 대상자에게 불리한 변경이면 경과조치를 검토한다.
- 부칙은 날짜를 헤더에 붙이는 학교 관행이 있으면 따른다: `부    칙 (2026. 11. 13.)`

### 5. 날짜·숫자·단위
- 날짜: `2026. 11. 13.` (연·월·일 뒤 마침표, 0 붙이지 않음), 본문 서술형은 `2026년 11월 13일`
- 기간: `〇일 이내`, `〇개월`, `〇년` / 범위: `1천만원 이상 3천만원 미만`
- 기준 표현을 명확히: 이상·이하(포함), 초과·미만(불포함). `~부터 ~까지`
- 금액: `100만원`, `1억 2천만원` (단위 붙여 쓰기 관행 유지)
- 비율: `100분의 50` (법령식) 또는 `50퍼센트` — 현행 규정 표기를 따름

### 6. 문장·용어
- 문장은 짧고 명확하게, 주어와 서술어를 호응시킨다. 하나의 문장에 하나의 내용.
- 의무: `~하여야 한다`, 재량: `~할 수 있다`, 금지: `~해서는 아니 된다`, 간주: `~으로 본다`, 추정: `~으로 추정한다`
- 지양 표현 → 권장 표현
  - `~할 시` → `~할 때`, `~하는 경우`
  - `~에 의하여` → `~에 따라`
  - `~토록 한다` → `~하도록 한다`
  - `동조`, `동항`, `동법` → `같은 조`, `같은 항`, `같은 법`
  - `익일` → `다음 날`, `금번` → `이번`, `기타` → `그 밖의`
  - `~에 있어서` → `~에서`, `~에 대하여` 남용 금지
  - `상기`, `하기` → `위`, `아래` / `지급하여야 할 것이다` → `지급하여야 한다`
- 같은 대상은 규정 전체에서 같은 용어로 쓴다(정의 조항 용어 준수).
- 직명·부서명은 현행 직제규정의 공식 명칭을 쓴다.
- 한자어·외래어는 가능한 한 쉬운 우리말로, 약어는 처음 나올 때 풀어 쓴다.

### 7. 띄어쓰기·문장부호
- 의존명사 띄어쓰기: `할 수 있다`, `한 때`, `〇〇 등`
- `및`, `또는`, `그 밖에` 앞뒤 띄어 쓰기. 나열은 `A, B 및 C` (마지막 연결어 앞 쉼표 없음)
- 가운뎃점(·)은 대등한 단어 연결에만: `교원·직원`
- 호·목 나열의 끝: 각 호는 명사형 또는 `~하는 경우`로 끝내고 마침표를 찍는 현행 관행 유지

### 8. 개정 방식 판단
- 일부개정: 변경 조문이 전체의 약 1/2 미만인 경우
- 전부개정: 체계 전반을 바꾸거나 변경 범위가 큰 경우 — 조문 번호를 새로 정리하고 개정 이력을 새로 시작
- 폐지: 다른 규정으로 통합되거나 근거가 소멸된 경우 — 폐지 규정 및 관련 규정 정비 동시 검토
